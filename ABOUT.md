# About MyTunes Redux Modern

Version: 2.0.0 "Reborn"

## Dedication
In memory of Bill Zeller, creator of the original myTunes and myTunes Redux.
His curiosity about how iTunes sharing worked inspired this modern reimagining.

## How this was created
This initial recreation was produced through reverse-engineering analysis of the
original installer and application using REA (Reverse Engineering Anything),
followed by a clean-room modern reimplementation. Shout-out to the REA tooling
and to Beam Free for assisting with the analysis and rebuild planning.


DAAP authentication in iTunes 7+ / Home Sharing remains proprietary.
